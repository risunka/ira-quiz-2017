ИРА ПЕРЦОВСКАЯ — ВКонтакте 2017
Первая рабочая версия сайта (автономный прототип), 15 ноября 2026

СОСТАВ
- index.html / styles.css / app.js
- assets/: 11 аватарок, 20 сохранёнок, изображения стены и квиза
- 22 основных вопроса и 3 резервных в коде

КАК ОТКРЫТЬ
1. Распакуйте ZIP.
2. Для просмотра откройте index.html в браузере. Лучше использовать локальный
   HTTP-сервер (например, python -m http.server 8000) и адрес http://localhost:8000/.
3. В профиле нажмите «Добавить в друзья» и зарегистрируйте тестового участника.
4. На странице квиза нажмите «Я организатор» -> «Начать игру».
5. Чтобы проверить несколько ролей на одном компьютере, зарегистрируйте людей
   в этой же браузерной среде и используйте «Сменить участника для теста».
6. Для повторной проверки используйте «Сбросить тестовую игру».

ЧТО УЖЕ РАБОТАЕТ
- Старинный дизайн профиля ВК, раскрытие анкеты, стена, комментарий.
- Разделы: друзья, фотоальбомы, 20 сохранёнок, 15 аудиозаписей, группы.
- Сетка друзей с именами и согласованными изображениями.
- Лайтбокс фотографий; мобильная адаптация.
- Регистрация 11 игроков по командам 4/4/3, назначение капитана.
- 17 командных и 5 индивидуальных вопросов.
- Отправка ответов с фиксацией, рейтинги и разбор после раунда.
- Вопросы на порядок, бинго, текст, фото и числа; 3 резервных вопроса.
- Оценка результатов и рейтинги в рамках браузера.

ВАЖНЫЕ ОГРАНИЧЕНИЯ ЭТОЙ ВЕРСИИ
- Это ЛОКАЛЬНЫЙ прототип, не готовый сервер для 11 разных телефонов.
  Используется localStorage, а не Supabase. Для реальной игры между смартфонами
  нужен сервер, авторизация организатора и проверка ответов на сервере.
- Правильные ответы пока находятся в app.js: не публикуйте эту версию
  как соревновательную до переноса ответов на сервер.
- Изображение с шаром пока НЕ отретушировано: вместо фото показывается
  скрытое размытое превью и предупреждение. Нужна настоящая ретушь.
- Аудиозаписи являются списком без воспроизведения; права на треки и
  аудиофайлы отдельно не предоставлены.
- Аватар Иры планируется сделать на самом празднике.
- Часть картинок друзей экспортирована из ранее утверждённой галереи:
  для высококачественного полноэкранного отображения могут понадобиться
  отдельные версии оригинальных согласованных аватарок.
- Ссылка на GitHub Pages пока не создана и Supabase не подключён.

ЗАМЕЧАНИЕ
Не изменять утверждённый текст квиза, список друзей, песни и сохранёнки
без согласования с организатором.
